# Electric Freestyle

An arcade freestyle game where you ride an electric (power) wheelchair around Sunset Yard, a concrete skatepark at sunset. Chain hops, flips, grabs, spins, grinds and wheelies into big combos, finish goals, unlock chair upgrades, and take on four new daily goals every day.

**Play:** https://kremzr.github.io/electric-freestyle/

The whole game is one self-contained HTML file (`index.html`). Every model, texture and sound is generated in code, so it runs offline: download `index.html` and open it in Chrome, Edge or Firefox.

## Controls
- Works with a controller (Standard Gamepad layout) or the keyboard.
- Keyboard: WASD / arrows drive, Space hop (hold to charge), J flip, K grab, L grind / wheelie, Q / E spin, Shift boost, Esc pause.
- Controls can be remapped from the Controls screen.
